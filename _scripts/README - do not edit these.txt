===============================================================
 _scripts  -  THE MACHINERY
 You do not need to open or run anything in here.
===============================================================

Run "UPDATE WEBSITE.bat" in the folder ABOVE this one instead.
It runs all of these for you, in the correct order.

These files are only documented here in case you (or someone
helping you) ever need to understand or change them.


WHAT EACH FILE DOES
-------------------

Update-Website.ps1
    The conductor. Runs the three steps below in order, then
    prints page weights and checks nothing is broken.
    This is what UPDATE WEBSITE.bat calls.

Update-Text.ps1
    STEP 1. Reads content.txt and writes the wording into the
    HTML, using invisible <!--T:key--> markers in the pages.
    Also writes content.projects.txt for the sync script.
    Pass -AutoRun to stop it pausing at the end.

Make-Thumbnails.ps1
    STEP 2. Creates 600px copies of your photos into "thumbs"
    subfolders. Skips ones already done. Deletes thumbnails
    whose original photo was removed. Never modifies originals.

sync-website.ps1
    STEP 3. Rebuilds all the photo grids, regenerates
    projects.html completely, and picks a random hero image.
    Auto-detects project folders.

content.projects.txt
    AUTO-GENERATED by Update-Text.ps1. Do not edit by hand.
    projects.html is rebuilt from scratch every sync, so its
    wording can't live in the HTML - it's passed through here.

_install-text-markers.ps1
    One-time setup, already run. It inserted the <!--T:key-->
    markers into the HTML. Safe to re-run (it skips anything
    already marked) but you shouldn't need to.

Update-Text.bat / Sync-Website.bat
    Older single-step launchers. Still work, but
    "UPDATE WEBSITE.bat" is safer because it always runs the
    steps in the right order.

Optimize-Images.ps1 / .bat
    DEAD. Only acts on files over 1 MB AND wider than 2000px.
    Every photo is already under 2000px, so it does nothing at
    all while reporting success. Use Make-Thumbnails.ps1.
    Safe to delete.


HOW THE PIECES CONNECT
----------------------

    content.txt
        |
        v
    Update-Text.ps1 ---> writes text into the HTML markers
        |                 and into content.projects.txt
        v
    Make-Thumbnails.ps1 -> images\...\thumbs\
        |
        v
    sync-website.ps1 ---> rebuilds grids using thumbs for the
                          grid and data-full for the lightbox


THINGS THAT WILL BREAK IT
-------------------------

- Deleting the <!--T:key--> markers from the HTML.
  The text updater finds nothing and silently stops working.

- Editing the .html files by hand. The photo grids and all of
  projects.html get overwritten on the next sync.

- Putting your own files inside a "thumbs" folder. They get
  deleted as orphans if there's no matching original.

- Moving this _scripts folder. Every script expects to sit one
  level below the website root.
